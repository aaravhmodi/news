# The Brief

Headlines from credible outlets (CBC, Globe and Mail, The Hindu, Indian Express, BBC, NPR, Guardian,
MIT Tech Review, Ars Technica, The Verge, TechCrunch, IEEE Spectrum), six times a day.

- Read: https://aaravhmodi.github.io/news/
- Phone alerts: install the **ntfy** app and subscribe to the topic stored in the `NTFY_TOPIC` repo secret.
- Change sources: edit `FEEDS` in `news.py`.
- Run now: Actions → news → Run workflow. Locally: `python news.py` (prints the digest instead of pushing).
